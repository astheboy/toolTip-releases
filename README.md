# toolTip for Windows

입력 언어 배지, 화면 캡처, 화면 글자 복사, 번역을 한 번에 하는 Windows 10·11용 작은 도구예요.

이 저장소는 **배포 전용**이에요. 실행 파일은 [Releases](https://github.com/astheboy/toolTip-releases/releases/latest)에서 받아요.

## 내려받기

**[최신 버전 내려받기 (toolTip-win-x64.zip)](https://github.com/astheboy/toolTip-releases/releases/latest/download/toolTip-win-x64.zip)**


## 설치

1. `toolTip-win-x64.zip`의 압축을 풀고, `toolTip.exe`를 계속 둘 폴더로 옮겨요(예: `문서\toolTip`).
   - .NET 등을 따로 설치할 필요가 없어요. 관리자 권한도 필요 없어요.
2. `toolTip.exe`를 더블클릭해요.
   - **"Windows의 PC 보호" 파란 창이 뜨면** → **추가 정보** → **실행**을 눌러요. 서명하지 않은 프로그램이라 처음 한 번 뜨는 경고예요.
3. 화면 오른쪽 아래 알림 영역에 toolTip 아이콘이 생겨요. 안 보이면 **^**(숨겨진 아이콘 표시)를 눌러 보세요. 아이콘을 작업 표시줄로 끌어 두면 편해요.
4. 아이콘 메뉴에서 **Windows 시작 시 자동 실행**을 켜 두세요.

## 사용법

- **입력 언어 배지**: 입력창을 클릭하면 커서 옆에 빨간 **ㅎ**(한글) 또는 파란 **A**(영문)가 잠깐 떠요. 메뉴에서 "항상 표시"로 바꿀 수 있어요.
- **왼쪽 Ctrl + 왼쪽 Alt를 누른 채 드래그**하면 메뉴가 떠요.
  - `1` 캡처를 클립보드로 복사해요. 이어서 `S`를 누르면 바탕화면에 저장, `B`를 누르면 흐린 배경으로 꾸며요.
  - `2` 캡처를 화면에 띄워요. 끌어서 배치하고 오른쪽 클릭으로 합쳐 저장해요.
  - `3` 화면 글자를 복사해요.
  - `4` 번역해요(아래 DeepL 키 필요).
- 다른 프로그램과 단축키가 겹치면 메뉴 → **영역 선택** → **Ctrl+Shift + 드래그**로 바꿔요.

## 번역 쓰기 (DeepL 무료 키)

1. 메뉴 → **DeepL API 키 설정…** → **DeepL 무료 API 키 받으러 가기**
2. 'API Free'로 가입해요. 카드 등록이 필요하지만 무료 요금제는 청구되지 않아요(월 50만 자).
3. 계정 → API Keys에서 키(끝이 `:fx`)를 복사해 붙여 넣고 **저장**해요.

> 번역할 글은 DeepL 서버로 보내져요. **학생 개인정보가 담긴 자료는 번역하지 마세요.**

## 한글이 인식되지 않을 때

글자 복사(`3`)에서 한글이 깨지면, 한국어 '광학 문자 인식' 기능이 없는 경우예요.
**설정 → 시간 및 언어 → 언어 및 지역 → 한국어 옆 ⋯ → 언어 옵션**에서 **광학 문자 인식**을 설치해요.

## 문제가 있을 때

- **관리자 권한으로 실행된 프로그램** 위에서는 드래그와 배지가 동작하지 않아요(Windows 보안 규칙).
- 보안 프로그램이 toolTip을 막으면 예외로 등록해 주세요(키보드·마우스 입력을 감지하는 프로그램이라 의심받을 수 있어요).
- 시작 메뉴에서 실행 창(Win+R)을 열고 `"toolTip.exe가 있는 경로" --diagnose`를 실행하면 진단 보고서가 열려요. 보고서와 `%APPDATA%\toolTip\error.log` 파일을 보내 주시면 원인을 찾기 쉬워요.
- 완전히 지우려면 메뉴에서 자동 실행을 끄고 종료한 뒤, `toolTip.exe`와 `%APPDATA%\toolTip` 폴더를 지워요. DeepL 키는 제어판 → 자격 증명 관리자 → Windows 자격 증명 → `toolTip/deepl-api-key`에서 지워요.
